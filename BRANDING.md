# SQLPulse - Brand Guidelines

## Brand Identity

**Name:** SQLPulse
**Tagline:** Real-time SQL Query Management & Automation

## Visual Identity

### Logo
- **Primary Logo:** Letter "S" in a gradient-filled rounded square
- **Gradient:** Blue (#3B82F6) to Cyan (#06B6D4)
- **Shape:** Rounded square (border-radius: 0.5rem)

### Color Palette

**Primary Colors:**
- Blue: #3B82F6 (rgb(59, 130, 246))
- Cyan: #06B6D4 (rgb(6, 182, 212))
- Gradient: from-blue-600 to-cyan-600

**Status Colors:**
- Success: #10B981 (Emerald)
- Warning: #F59E0B (Amber)
- Error: #EF4444 (Red)
- Info: #3B82F6 (Blue)

**Neutral Colors:**
- Dark: #111827 (Gray-900)
- Medium: #6B7280 (Gray-500)
- Light: #F9FAFB (Gray-50)

### Typography
- **Font Family:** System fonts (Inter, SF Pro, Segoe UI)
- **Headings:** Bold, often with gradient text effect
- **Body:** Regular weight, gray colors for hierarchy

### Design Principles

1. **Minimalist:** Clean, uncluttered interfaces
2. **Modern:** Gradient accents, rounded corners, shadows
3. **Professional:** Business-appropriate aesthetics
4. **Accessible:** High contrast, clear typography
5. **Responsive:** Mobile-first design approach

### UI Components

**Cards:**
- Rounded corners: 0.75rem - 1rem
- Shadow: lg to xl on hover
- Border: Subtle gray-100/gray-700
- Hover: Scale effect on icons (1.1x)

**Buttons:**
- Primary: Gradient (blue-600 to purple-600)
- Secondary: Solid colors
- Rounded: 0.5rem
- Shadow: md, increases on hover

**Icons:**
- Style: Outline/stroke based
- Size: Consistent scaling (w-4 h-4 to w-7 h-7)
- Color: White on colored backgrounds, gradient for emphasis

### Navigation
- Centered pill-style menu items
- Active state: Gradient background
- Icons: Meaningful SVG icons (not emojis in production)
- Responsive: Collapsible mobile menu

## Marketing Positioning

**Target Audience:**
- Database Administrators
- Data Engineers
- DevOps Teams
- Analytics Teams

**Key Features:**
- SQL Query Library & Management
- Automated Query Scheduling
- Multi-Database Support
- Execution History & Monitoring
- Template Library
- Real-time Dashboard

**Value Proposition:**
"Streamline your SQL workflow with intelligent query management, automation, and monitoring - all in one beautiful platform."
