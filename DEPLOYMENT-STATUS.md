## Services

### Frontend - Cloudflare Pages
- **Platform**: Cloudflare Pages
- **URL**: https://sqlpulse.pages.dev/
- **Stack**: React 18 + Vite + TypeScript + Tailwind CSS
- **Cost**: $0/month (Free tier)
- **Auto-deploy**: On git push to `main`

### Backend - Fly.io
- **Platform**: Fly.io
- **URL**: https://sqlpulse-backend.fly.dev/
- **Stack**: Node.js 18 + Express.js + Sequelize ORM
- **Region**: Tokyo (NRT)
- **Cost**: $0/month (Free tier - 3 shared-cpu-1x instances)
- **Auto-deploy**: Manual via `flyctl deploy`

### Scheduler - Fly.io
- **Platform**: Fly.io
- **URL**: https://sqlpulse-scheduler.fly.dev/ (background)
- **Stack**: Node.js 18 + Bull Queue + node-cron
- **Region**: Tokyo (NRT)
- **Cost**: $0/month (Free tier)
- **Auto-deploy**: Manual via `flyctl deploy`

### Database - Supabase
- **Platform**: Supabase (PostgreSQL 14)
- **Connection**: Connection pooling enabled
- **Storage**: 500MB (Free tier)
- **Cost**: $0/month
- **Backups**: Automatic daily backups included

### Redis - Upstash
- **Platform**: Upstash Redis
- **Type**: Global serverless Redis
- **Limit**: 10,000 commands/day
- **Cost**: $0/month (Free tier)

## Updates & Maintenance

### To Deploy Code Updates:

1. **Make changes locally**
2. **Test with Docker Compose**:
   ```bash
   docker compose up --build
   ```
3. **Commit and push**:
   ```bash
   git add .
   git commit -m "Your update message"
   git push
   ```
4. **Deploy backend**:
   ```bash
   cd backend
   flyctl deploy
   ```
5. **Deploy scheduler**:
   ```bash
   cd ../scheduler
   flyctl deploy
   ```
6. **Frontend auto-deploys** on git push

### To Update Environment Variables:

**Backend/Scheduler (Fly.io)**:
```bash
flyctl secrets set KEY=value -a sqlpulse-backend
flyctl secrets set KEY=value -a sqlpulse-scheduler
```

**Frontend (Cloudflare)**:
1. Go to Cloudflare Dashboard
2. Workers & Pages → sqlpulse → Settings
3. Environment variables → Edit variables
4. Redeploy

## Troubleshooting

### Backend/Scheduler not responding (503)
```bash
# Check logs
flyctl logs -a sqlpulse-backend

# Check if running
flyctl status -a sqlpulse-backend

# Restart
flyctl apps restart sqlpulse-backend
```

### CORS errors
- Verify `CORS_ORIGIN` is set to `https://sqlpulse.pages.dev`
- Check backend logs for CORS-related errors

### Database connection errors
- Verify DATABASE_URL is correctly encoded (# → %23)
- Check Supabase dashboard for connection limits
- Test connection: `psql "postgresql://..."`

### Redis connection errors
- Verify REDIS_URL in both backend and scheduler
- Check Upstash dashboard for connection errors
- Test connection: `redis-cli -u rediss://...`

### Frontend not loading
- Check Cloudflare Pages build logs
- Verify VITE_API_URL is correct
- Clear browser cache
